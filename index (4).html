Sobre Mí

¡Hola! Soy Katherine, Backend Developer Junior. Mi enfoque está en el desarrollo backend, donde me interesa construir APIs, trabajar con bases de datos y entender cómo funcionan los sistemas desde su núcleo.

Trabajo principalmente con Java y Spring Boot, junto con bases de datos relacionales como MySQL y PostgreSQL. También manejo Git, GitHub, HTML, CSS y JavaScript para complementar el desarrollo de soluciones web.

Me caracterizo por la curiosidad, la disciplina y el enfoque en resolver problemas. Busco escribir código limpio, aprender buenas prácticas y convertir necesidades concretas en soluciones digitales funcionales.
